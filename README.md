# Zyro Player

**Zyro Player** — неофициальный Android-клиент SoundCloud с полноценным
плеером, офлайн-режимом, текстами песен и собственной дизайн-системой.

> Проект не связан с SoundCloud. Использование сервиса регулируется правилами
> SoundCloud; треки с меткой **GO+** требуют соответствующей подписки.

---

## Возможности

### Музыка и SoundCloud
- Вход через SoundCloud (OAuth Authorization Code + PKCE).
- Лента активности подписок и рекомендации «Найти».
- Поиск треков, артистов, альбомов и плейлистов.
- Лайки треков, артистов и плейлистов.
- Собственные и серверные плейлисты: создание, редактирование, добавление треков.
- Страницы артистов, альбомов и плейлистов.
- Прохождение капчи DataDome внутри приложения, если SoundCloud запросил проверку.

### Плеер
- Воспроизведение через **Media3 ExoPlayer** (MP3 и HLS-потоки SoundCloud).
- Мини-плеер и полноэкранный плеер.
- Очередь с перестановкой треков, удалением и очисткой.
- Shuffle с антиповторами и режимы повтора.
- **Скорость воспроизведения** от 0,5× до 2×.
- **Системный эквалайзер** с пресетами и сохранением настроек.
- Фоновое воспроизведение, медиа-уведомление и управление с локскрина.
- Восстановление очереди и позиции после перезапуска приложения.

### Офлайн и медиатека
- Скачивание треков, альбомов и плейлистов для прослушивания без сети.
- Аудио-кеш текущих и следующих треков.
- История прослушивания.
- Локальные плейлисты и лайки.
- Отдельный экран офлайн-настроек.

### Дополнительно
- Синхронизированные и обычные тексты песен (LRCLIB и Musixmatch).
- Комментарии SoundCloud с таймкодами и автоподгрузкой.
- Комментарии поверх обложки во время воспроизведения.
- Тёмная и светлая темы, выбор шрифта.
- Дизайн-система «plastic glass»: полупрозрачные панели, свечение и
  плавные анимации на базе Jetpack Compose.

## Структура проекта

Проект состоит из одного модуля `:app`, namespace `com.zyro.player`.

```text
app/src/main/java/com/zyro/player/
├── data/
│   ├── auth/          # сессия SoundCloud, OAuth, cookies, капча
│   ├── local/         # Room: треки, история, плейлисты
│   ├── remote/        # SoundCloud API, поиск, лента, комментарии, тексты
│   └── downloader/    # офлайн-скачивание и кеш аудио
├── player/            # ExoPlayer, очередь, медиа-сессия, foreground-сервис
└── ui/
    ├── components/    # плеер, шторки, карточки, дизайн-система
    ├── screens/       # главная, лента, поиск, медиатека, онбординг
    ├── theme/         # темы, цвета, шрифты
    └── MainViewModel.kt
```

Основные точки входа:
- `MainActivity.kt` — корневая навигация и глобальные слои.
- `MainViewModel.kt` — состояние экранов и связка с репозиториями.
- `player/AudioPlayerManager.kt` — воспроизведение и настройки звука.
- `ui/components/FullPlayerSheet.kt` — полноэкранный плеер.

## Сборка

### Требования
- Android Studio (актуальная версия);
- JDK 17 или новее;
- Android SDK с API 36.

### Debug-сборка

```bash
# Windows
.\gradlew.bat :app:assembleDebug

# macOS / Linux
./gradlew :app:assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/`.

### Release-сборка

Для подписи release-сборки используются переменные окружения:

```text
KEYSTORE_PATH   — путь к .jks-файлу
STORE_PASSWORD  — пароль хранилища
KEY_PASSWORD    — пароль ключа
```

Параметры подписи описаны в `app/build.gradle.kts`.

### Firebase / Google Services

Файл `google-services.json` в репозиторий не входит. Плагин настроен в режиме
`WARN`, поэтому сборка работает без него. Если понадобятся Firebase-функции,
добавьте файл локально — он исключён через `.gitignore`.

### Секреты

Локальные секреты и настройки окружения не коммитятся:

- `.env` — реальные ключи;
- `local.properties` — путь к Android SDK;
- `*.jks` / `*.keystore` — ключи подписи.

Шаблон переменных окружения находится в `.env.example`.
